Copy these into a project when running Build OS (SKILL.md §0 Step 5). Sections map 1:1 to the
questions' "📄 Creates" targets, so every project's artifacts share the same structure and are
comparable across the dashboard. `<angle-bracket>` text is a placeholder; delete sections only via a
logged decision (DECISION_LOG.md), never silently.
